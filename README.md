# Analog IC Designs (aicex - SKY130A)

Analog IC designs done using the [aicex](https://analogicus.com/aicex/) framework on the SKY130A open-source PDK.

## Designs

| Design | Description |
|--------|-------------|
| `lelo_ex_sky130a` | Basic exercise design |
| `lelo_ex1_sky130a` | Exercise 1 - amplifier design with AC/DC/OP/tran analyses |
| `lelo_5tota_sky130a` | 5-transistor OTA design |
| `lelo_modele_sky130a` | NMOS model characterization |
| `lelo_pmodele_sky130a` | PMOS model characterization |

## Tools

- [xschem](https://xschem.sourceforge.io/) - Schematic editor
- [ngspice](http://ngspice.sourceforge.net/) - SPICE simulator
- [cicsim](https://github.com/wulffern/cicsim) - Simulation framework
- SKY130A PDK
