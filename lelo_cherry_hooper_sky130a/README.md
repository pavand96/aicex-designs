# LELO_CHERRY_HOOPER — Cherry-Hooper Differential Amplifier

Wide-bandwidth two-stage differential amplifier on **SKY130A**, sized for **maximum gain-bandwidth (GBW)**.

## Topology

- **Stage 1**: NMOS differential pair `M1/M2` with PMOS current-source loads `I3/I4` and tail `ISS1`
- **Stage 2**: NMOS common-source pair `M3/M4` with PMOS loads `I1/I2`, tail `ISS2`, and **shunt feedback resistors `RF`** from each output back to the same-side `M3/M4` gate (which is also the `M1/M2` drain node)
- The Cherry-Hooper trick: `RF` collapses the impedance at the inter-stage nodes (`nA`, `nB`) to ≈ `1/gm3`, removing what would otherwise be a low-frequency pole and dramatically extending the bandwidth

## Sizing (typical, tt corner, 27 °C, 1.8 V)

| Device | Type | W (µm) | L (µm) | Role |
|--------|------|--------|--------|------|
| M1, M2 | NFET | 60 | 0.5 | Input pair |
| M3, M4 | NFET | 15 | 0.5 | 2nd-stage CS |
| MT1 (ISS1) | NFET | 80 | 1.0 | Stage-1 tail |
| MT2 (ISS2) | NFET | 80 | 1.0 | Stage-2 tail |
| MI1, MI2 | PFET | 20 | 1.0 | Output PMOS loads |
| MI3, MI4 | PFET | 20 | 1.0 | Stage-1 PMOS loads |
| RF1, RF2 | R | – | – | 6 kΩ shunt feedback (sized for ~20 dB midband gain) |

Bias gates are driven externally by `VBIASN = 0.7 V` and `VBIASP = 0.4 V`.

## Operating point

| Quantity | Value |
|---|---|
| Branch current (per side) | 105 µA |
| ISS1 / ISS2 tail current | 210 / 218 µA |
| PMOS load current per branch | 103 µA |
| `VOUTP` = `VOUTN` | 1.14 V |
| `nA` = `nB` | 1.14 V |
| `gm` M1 (input) | **2.0 mS** |
| `gm` M3 (2nd stage) | **1.25 mS** |
| `gds` M3 / I1 (load) | 13.2 µS / 5.5 µS |
| Total `IDD` | ≈ 850 µA |

All devices confirmed in saturation.

## AC results (CL = 100 fF differential)

| Spec | Value |
|------|------:|
| **Differential DC gain** | **20.04 dB** (≈ 10.0 V/V) |
| **−3 dB bandwidth** | **1.12 GHz** |
| **GBW** | **2.90 GHz** |
| Phase behavior | Single-pole roll-off, no peaking |

This sizing was reached after sweeping `RF` to hit a ~20 dB target — see [`context.md`](../context.md) for the full convergence story.

## Why this maximises GBW

The Cherry-Hooper restructures the bandwidth limit:
- Conventional 5T OTA: `GBW ≈ gm1 / (2π × CL_total)` where `CL_total` is dominated by the intrinsic high-impedance node capacitance Miller-multiplied by the second stage gain.
- Cherry-Hooper: `RF` makes the inter-stage node low-impedance (≈ `1/gm3` ≈ 800 Ω here). The pole at that node is pushed past the unity-gain frequency. The remaining output pole is `≈ gm3 / CL`, also very high.

Comparison vs the LELO_5TOTA design in this same repo:

| Design | IDD | DC gain | GBW | GBW/µA |
|--------|-----|---------|-----|--------|
| LELO_5TOTA (PMOS in) | 8.5 µA | 37 dB | 7.9 MHz | 0.93 MHz/µA |
| LELO_CHERRY_HOOPER | 850 µA | 20.0 dB | **2.90 GHz** | **3.4 MHz/µA** |

GBW improved ~300×; GBW per current ~3× — a textbook Cherry-Hooper trade-off (trades gain for bandwidth at the same current density).

## Running the sims

The netlist must NOT be regenerated by `make typical` (it would overwrite the hand-written one). Run cicsim directly:

```bash
cd sim/LELO_CHERRY_HOOPER
cicsim run --name Sch_typical op Sch Gt Ktt Tt Vt
cicsim run --name Sch_typical ac Sch Gt Ktt Tt Vt
```

## Design knobs

| To increase | Adjust |
|-------------|--------|
| **GBW** | Lower `CL`, increase tail current (raise `VBIASN`), shrink `RF` |
| **DC gain** | Lengthen M3/M4 (`L 0.5 → 1`), increase `RF`, lengthen PMOS loads |
| **Phase margin** | Raise `RF` (slower but more damped) |

## Caveats

1. SKY130A `L = 0.15 µm` was tried — `gm` rises but `gds` rises faster, dropping intrinsic gain below 1 dB. Sweet spot for max-GBW with usable gain is `L = 0.5 µm`.
2. The current-mirror bias generator (NMOS + PMOS diodes) is omitted; `VBIASN`/`VBIASP` are forced via voltage sources to avoid DC convergence issues encountered with the binned SKY130A models.
3. All devices use `nf = 1` because ngspice multi-finger devices break the `@m.<inst>.<model>[id]` access strings used in the OP measurement script.
